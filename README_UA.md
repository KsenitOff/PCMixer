# PC Mixer — touch-мікшер зі старого телефона

## Що реалізовано

- **FIXED**: 5 фейдерів.
  - №1 — остання програма у фокусі Windows, яка має аудіосесію.
  - №2–5 — чотири фіксовані програми.
- **ACTIVE**: усі програми/аудіосесії, які зараз присутні у Windows Audio Mixer.
- Однакові процеси (наприклад кілька audio sessions Chrome) агрегуються в один канал; зміна фейдера застосовується до всіх таких sessions.
- Tap по 🔊/🔇 — mute/unmute.
- ⚙ — налаштування 4 fixed-програм без редагування файлів.
- ⛶ — fullscreen на телефоні.
- Сторінка намагається тримати екран увімкненим через Screen Wake Lock API, якщо браузер це підтримує.
- Усе працює **локально**, без хмари та акаунтів.

## Вимоги

- Windows 10/11.
- Python 3.10, 3.11 або 3.12 (під час інсталяції потрібен Інтернет для встановлення Python-пакетів).
- ПК і телефон в одній локальній мережі.

## Встановлення

1. Встанови Python 3.10–3.12, якщо його ще немає. При встановленні познач **Add python.exe to PATH**.
2. Завантаж репозиторій через **Code → Download ZIP** і розпакуй у постійну папку, наприклад `C:\Tools\PCMixer`. У репозиторії немає `.venv`: вона створиться на цьому ПК.
3. Двічі запусти **`Install_PC_Mixer.bat`**.
4. Скрипт:
   - створить локальне Python-оточення `.venv`;
   - поставить FastAPI / Uvicorn / pycaw / psutil;
   - створить ярлики **PC Mixer** та **Stop PC Mixer** на Desktop і в папці програми;
   - запустить PC Mixer.
5. Якщо Windows Firewall покаже запит — дозволяй **Private networks**. Public network не потрібен.
6. На ПК відкриється сторінка PC Mixer. Натисни ⚙ і подивись блок **Open on phone**. Там буде адреса на кшталт:

   `http://192.168.1.25:8765`

7. Введи цю адресу в браузері старого телефона. Для стаціонарного використання збережи її на Home Screen / як закладку.

## Якщо телефон не відкриває сторінку

1. Переконайся, що ПК і телефон в одному Wi‑Fi/LAN.
2. У Windows мережа повинна мати профіль **Private**, а не Public.
3. Запусти **`Enable_LAN_Access.bat`** — він попросить UAC і додасть inbound firewall rule лише для TCP 8765 у Private profile.
4. VPN на ПК/телефоні іноді блокує локальну мережу — для тесту вимкни його.

## Налаштування FIXED

Натисни ⚙. Для кожного з чотирьох fixed-каналів обери програму зі списку поточних аудіосесій Windows. У списку видно назву програми та її `.exe`. Можна також обрати `Enter .exe manually…` і вписати executable, наприклад:

- `Discord.exe`
- `Spotify.exe`
- `chrome.exe`
- `firefox.exe`

Якщо програма зараз закрита, попередньо призначений канал залишається у списку з позначкою `offline`. Нову закриту програму можна вписати вручну; фейдер покаже `OFFLINE`, поки аудіосесія не з'явиться. Один застосунок можна призначити кільком каналам: їхні фейдери рухатимуться разом.

## Поведінка FOCUS

Перший фейдер FIXED визначається через foreground window Windows. Якщо активне вікно не має поточної audio session, фейдер залишається на останній програмі у фокусі, яка має audio session. Після запуску сервера, доки такої програми ще не було, канал показує `No focused app`. Якщо остання програма втратить audio session, канал теж показуватиме `No focused app` до появи наступної програми зі звуком у фокусі.

## ACTIVE

Після оновлення файлів перезапусти сервер і один раз онови сторінку на ПК та телефоні, щоб браузери завантажили новий код керування фейдерами.

ACTIVE показує audio sessions, які повертає Windows Core Audio у цей момент. Це не список усіх запущених `.exe`, а саме список застосунків, які Windows тримає в audio mixer.

## Запуск надалі

Просто двічі клацни **PC Mixer** на робочому столі або ярлик у папці програми. Також можна запустити `Start_PC_Mixer.bat` із папки програми. Сервер запуститься приховано, без консолі, та відкриє локальну сторінку на ПК. Якщо сервер уже працює, другий запуск не створить ще одну копію.

Для зупинки — ярлик **Stop PC Mixer**. Повторно запускати інсталятор для звичайного старту не потрібно.

У ⚙ налаштуваннях є галочка **Start with Windows**. Постав її та натисни **SAVE**, щоб сервер автоматично запускався після входу в твій обліковий запис Windows. Браузер на ПК при цьому не відкриватиметься. Зніми галочку й натисни **SAVE**, щоб вимкнути автозапуск. Це налаштування початково вимкнене й діє лише для поточного користувача Windows.

## Де зберігаються налаштування

`%APPDATA%\PCMixer\config.json`

Сам архів/папку після інсталяції не видаляй: ярлик використовує Python-оточення з цієї папки.

## Як передати програму іншому ПК

Завантаж вихідний код репозиторію через **Code → Download ZIP** або склонуй його. Не копіюй встановлену `.venv` та готові `.lnk`: вони містять шляхи саме до цього ПК. На іншому комп'ютері розпакуй код у постійну папку й запусти `Install_PC_Mixer.bat`; інсталятор створить локальну `.venv` та ярлики з правильними шляхами. Якщо після інсталяції перемістити папку, ярлики й автозапуск треба налаштувати знову.

## Важливі обмеження MVP

- Це Python-проєкт, а не один self-contained `.exe`: на кожному новому ПК потрібні сумісний Python і одноразове встановлення залежностей. Після цього запуск відбувається одним ярликом.
- Windows іноді залишає audio session після того, як застосунок перестав реально звучати. ACTIVE відображає саме те, що бачить Core Audio/системний мікшер.
- Якщо один executable має кілька незалежних audio sessions з різними рівнями, UI показує їх середню гучність; при русі фейдера всі його sessions вирівнюються до одного значення.
- Немає авторизації. Не роби port forwarding для 8765 у роутері — сервіс призначений лише для домашньої LAN.
